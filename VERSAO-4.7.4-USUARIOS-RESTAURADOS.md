# Prefeitura Conecta v4.7.4

Esta versão restaura e protege a lista histórica de usuários do sistema.

## Usuários restaurados

- Todos os perfis originais voltam a aparecer no seletor de perfis cadastrados.
- Os usuários padrão são novamente incluídos quando uma cópia antiga ou incompleta dos dados salvos é carregada.
- Usuários convidados posteriormente continuam preservados.
- Alterações já feitas em perfis existentes também continuam preservadas.

## Segurança mantida

- Perfis do setor atual permanecem disponíveis para troca no ambiente demonstrativo.
- Os nomes de outros setores aparecem para confirmar que continuam cadastrados, mas ficam bloqueados para usuários comuns.
- Somente Prefeito e Vice-prefeito podem selecionar perfis de outros setores.
- A troca direta por código continua protegida pela mesma verificação, impedindo contorno pela interface.
