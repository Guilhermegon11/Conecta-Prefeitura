# Prefeitura Conecta v4.7.6

Esta versão libera a seleção de todos os perfis cadastrados no ambiente de demonstração, mantendo os dados isolados por setor.

## Perfis

- Todos os perfis ativos podem ser selecionados no cabeçalho.
- Ao selecionar um usuário comum, o sistema abre automaticamente o setor ao qual esse usuário pertence.
- O Prefeito permanece como perfil inicial.

## Isolamento mantido

- Chamados são filtrados pelo setor do perfil selecionado.
- Processos, contratos, documentos, eventos, funcionários, indicadores e registros operacionais seguem o mesmo setor.
- Usuários comuns não recebem o seletor para navegar entre setores.
- Somente Prefeito e Vice-prefeito podem escolher livremente qual setor visualizar.
- A Comunicação continua respeitando as regras adicionais de privacidade executiva.
